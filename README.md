🏡 Dream Home Website

Dream Home is a modern and user-friendly real estate website where users can explore, view, and buy houses in their preferred area. The website is built using HTML, CSS, and JavaScript, with attractive UI design and smooth CSS effects to provide a great user experience.

🌟 Features

🔐 User Authentication

User Registration

User Login

🏘️ View Houses

Browse all available houses

Filter houses based on user’s area

📝 House Details

View complete details of each house

Price, location, images, and description

🛒 Buy House

Users can select and buy houses

🎨 Modern UI Design

Best CSS animations and hover effects

Responsive design for all devices

⚡ Fast & Lightweight

Built using pure HTML, CSS, and JavaScript

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling, animations, and effects

JavaScript (JS) – Functionality and interactivity
